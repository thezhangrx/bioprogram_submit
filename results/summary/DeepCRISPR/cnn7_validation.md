# CNN7 × CRISPRon：Pos18 C→A 一致性验证

- 数据集：`DeepCRISPR`（细胞系 hct116/hek293t/hela/hl60）
- 模型：CNN，`sequence_kernel=7`，**纯序列**（`selected_environments=[]`），**四个细胞系全部数据既训练又评估**（无留出）
- 关注位点：第 **18** 位（1-based），只取原始碱基为 `C` 的序列，突变为 `A`
- 待检验的命题：把该位点由 `C` 变成 `A`，**会不会降低编辑效率**（即两个增量是否都为正、且方向一致）

## 三个主指标

1. **`cnn_pred-ism` 正号占比 = 0.7911**（4019 / 5080） —— 本项目 CNN7 判为**有害**（突变把预测效率**拉低**）的序列比例
2. **`crispron_wt-crispron_c18a` 正号占比 = 0.9039**（4592 / 5080） —— 外部预测器 CRISPRon 判为**有害**的序列比例
3. **`consistency` 正号率 = 0.7624**（3873 / 5080） —— 两者对「是否有害」判断**一致**（同号）的序列比例

> 总序列数 **5080**；可判方向 5080（并列 0，缺失 0）。
> `cnn_pred-ism` 均值 0.0913，`crispron_wt-crispron_c18a` 均值 0.1007 —— 两者尺度接近，可直接比较：CRISPRon 的方向性明显更强（0.9039 vs 0.7911），一致率只有 0.7624。

## 两个 `y_true-*` 列：请当作**噪声参照**读

这两列把**真实标签**卷了进来，因此它们的符号占比**不能**当作模型或 CRISPRon 的表现指标：

| 列 | 正号占比 | 说明 |
| :--- | ---: | :--- |
| `y_true-ism` | 0.5850 | 真实效率 − CNN7 对突变体的预测 |
| `y_true-crispron_c18a` | 0.2319 | 真实效率 − CRISPRon 对突变体的预测 |

两列的偏离方向**各有各的原因**，都不是突变效应：

**(1) `y_true-ism` 偏向 0.5 —— 被标签的序列间波动稀释。**

- `y_true-ism` 的标准差 **0.1342**，而 `cnn_pred-ism` 的均值只有 **0.0913** —— 噪声项比信号项大 1.47 倍
- `y_true-ism` 与 `cnn_pred-ism` 的相关系数仍高达 **0.8493** —— in-sample 下 `pred_wt ≈ y_true`，所以它**约等于** ISM 增量，但符号被标签涨落来回翻转，占比被推回 0.5850

**(2) `y_true-crispron_c18a` 远离 0.5 —— 被两个体系的尺度错配主导。**

它根本不是 50/50 的随机量，而是**几乎恒为负**：

| 量 | 均值 | 标准差 |
| :--- | ---: | ---: |
| 真实标签 `y_true` | 0.2954 | 0.1828 |
| CNN7 对 WT 的预测 | 0.3444 | 0.1753 |
| CNN7 对 C18A 的预测 | 0.2531 | 0.1250 |
| CRISPRon 对 WT 的预测 | 0.5389 | 0.1158 |
| CRISPRon 对 C18A 的预测 | 0.4382 | 0.1394 |

DeepCRISPR 的标签与 CRISPRon 的输出**不在同一尺度上**，所以「标签 − CRISPRon 预测」里叠了一个**恒定的系统性偏移**，突变效应只是叠加在它上面的小量。具体到本批：

- 真实标签均值约 **0.295**，而 CRISPRon 对突变体的预测均值约 **0.438**，系统性相差约 **-0.143**
- 而突变本身在 CRISPRon 尺度上的效应只有约 **0.1007**
- 结果：`y_true-crispron_c18a > 0` 的占比只有 **0.2319** —— 这个数字反映的是**两套体系的尺度差**，不是任何一方对突变的判断

> 两列都没有信息量可用：一列被方差淹没（0.5850），一列被尺度偏移淹没（0.2319）；而两个真正的增量是 0.7911 与 0.9039，方向性清楚得多。**判读只看后者。**

> 结论：判读方向一致性**只看** `cnn_pred-ism` × `crispron_wt-crispron_c18a`；两个 `y_true-*` 列保留在表里是为了**展示这两条噪声路径**，不是判据。

## 列的释义

命名约定：`ism` = **对 ISM 突变后序列的预测值**；`A-B` = `A − B`。

| 列 | 含义 |
| :--- | :--- |
| `cell_line` | 细胞系 |
| `sgRNA` | 23 nt 序列（20 nt protospacer + 3 nt PAM） |
| `y_true-ism` | 真实编辑效率 − CNN7 对**第 18 位改成 A 之后**的序列的预测效率 |
| `y_true-crispron_c18a` | 真实编辑效率 − CRISPRon 对 **C18A 突变体**的预测 |
| `cnn_pred-ism` | CNN7 对 **WT** 的预测 − 对 **C18A 突变体**的预测（模型自己的 ISM 增量） |
| `crispron_wt-crispron_c18a` | CRISPRon 对 **WT** 的预测 − 对 **C18A 突变体**的预测（外部预测器的同一增量） |
| `consistency` | `cnn_pred-ism` 与 `crispron_wt-crispron_c18a` **同号为 `+`，异号为 `-`**；任一列为 0 记 `0`；缺失留空 |

## 怎么读

- 三行的读法：两个正号占比各自回答「这一方判该突变**有害**（拉低效率）的序列占多少」，`consistency` 正号率回答「两方判断**同向**的序列占多少」。两列的正号都被定义成同一个方向，因此 `consistency` 的 `+` 等价于「两边都说有害」。
- 本次：CRISPRon 有 **0.9039** 的序列判为「有害」，CNN7 只有 **0.7911**，一致率 **0.7624**。即：**本项目模型没有复现 CRISPRon 对 PAM 近端位点突变的强方向先验。**
- ⚠️ **CNN7 是在同一批序列上训练又在同一批序列上预测的（in-sample）**，因此这是「模型已尽可能拟合标签后，仍与外部预测器不一致」的对照，不是泛化误差。
- ⚠️ 两个预测器都对同一批 30 nt 窗口取预测值；CRISPRon 用的是 WT 与突变体两个真实 30-mer，CNN7 用的是同一序列的 one-hot 张量。

> 完整逐序列数据见同目录 **`cnn7_validation.csv`**（5080 行）。本文件不含数据行。
